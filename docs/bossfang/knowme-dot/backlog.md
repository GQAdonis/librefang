## Placement, decision and release gates

The first owner-call release can be single-owner-per-data-plane. A shared control plane requires the separate tenant/isolation gate, not a cosmetic namespace. BossFang owns media orchestration and product projection; UAR remains execution/admission authority. UAR realtime design labels WebRTC media as planned; [#386](https://github.com/Prometheus-AGS/universal-agent-runtime/issues/386) records the specific missing media-action grant and receipt seam. KnowMe owns product surfaces and native mobile qualification; Charcoal is a separate client. Know Decision and KBD are advisory/phase governance, never a parallel tool-grant authority.

Record decisions still needed: first certified desktop/mobile matrix; supported local STT/LLM/TTS hardware/languages; TURN/LiveKit hosting and endpoint trust; optional hosted speech/avatar vendors; meeting platform admission contract; transcript retention default; mobile background policy; telephone provider/jurisdiction and takeover operator. These are blocking only for the milestone that uses them. No external calls, client data publication, production rollout, or runtime changes are authorized by this documentation audit.
