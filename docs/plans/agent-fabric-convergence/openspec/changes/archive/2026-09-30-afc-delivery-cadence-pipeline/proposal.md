## Why

Cadence currently holds delivery state across expensive work, blocks independent implementation on publication debt, and cannot reliably adopt an equivalent completed build. Scope splits can also lose the actual feature-operation contract, leaving missing delivery work to be discovered late.

## What Changes

- Add frozen candidates, one authorized work-ahead scope, short claim/execute/reconcile transactions and shared physical-output ownership.
- Preserve exact-source build/operation evidence through receipt adoption and recovery.
- Track durable publication obligations, per-platform attempts, meaningful scheduled opportunities and separate acceptance.
- Require feature-operation readiness and evidence limitations through planning, child scope splits and delivery boundaries.
- **BREAKING:** migrate mutable run state explicitly to schema v3; audited old writers cannot mutate it. Preserve history, backups and supported v1/v2 migration.
- Distribute identical shared implementation to full/mini packs through existing supported harness routes.
- Align initiative governance with the authorized 120-minute/every-two-deliveries policy while retaining manual override and stage feedback.

## Capabilities

### New Capabilities

- `delivery-cadence-pipeline`: bounded work-ahead, operation ownership, candidate evidence, publication debt, migration and distribution.

### Modified Capabilities

- `release-cadence-governance`: configured delivery intervals, authorized recurring publication, process-delivery operation and separate installed acceptance.

## Impact

Full/mini Delivery Cadence modules, schemas, KBD/goal/loop adapters, reports, source instructions and existing distribution metadata. One shared engine implementation; no new dependency, daemon or scheduler. Existing Boss workflow contracts are reused only where enforceable; missing exact-source or remote serialization capability remains blocked with an assigned follow-up. No Boss production code or Obsidian project changes belong here.

Implementation follows the reviewed child plan at `.kbd-orchestrator/phases/agent-fabric-convergence/children/delivery-cadence-pipeline/plan.md`. This artifact authorizes no execution.
