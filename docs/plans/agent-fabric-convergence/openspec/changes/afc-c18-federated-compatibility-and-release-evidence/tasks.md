These are delivery groups for the initiative, not ready-to-dispatch product assignments. Before applying a product group, expand it into bounded tasks in the affected repository's own OpenSpec/KBD root and record file claims, checkpoint and acceptance links. The initiative keeps the group pending until all child evidence passes. C01 only produces coordination documents.

**D01 mapping:** Reuse exact early local and conditional four-platform publication receipts where applicable, including GitHub artifacts, `RELEASES.md`/manifest commit, boss-landing-spot commit, Lovable deployment and live download-byte checks. This does not complete the C18 operational-mode matrix, federation fencing, quality benchmark or any original checkbox below. A recorded wait is pending publication, not a full release.
