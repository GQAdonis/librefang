# Proposal

## Why
UAR has a governed child-thread kernel but lacks one accepted, lossless contract for reusable teams, durable member activations and team protocol projections. Existing convergence proposals need a bounded local-first implementation path.

## What Changes
- Produce source-backed assessment, protocol compatibility decisions and a reviewable architecture proposal.
- After operator architecture approval, publish an official Draft Specification with schemas, examples, traces, migration mappings and implementation roadmap.
- Preserve the pending integration-administration acceptance and closeout as an external dependency.

## Capabilities
No deployed capability changes. This documentation-only change uses skip_specs; proposed runtime contracts stay in documentation until separately approved implementation changes.

## Impact
Coordination artifacts in this initiative; later canonical documents under UAR docs/agents/team-orchestration. No production code, dependency upgrades, migrations or application builds.
