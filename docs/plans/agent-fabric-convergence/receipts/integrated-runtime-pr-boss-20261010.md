### What this PR does

Before this PR: desktop v2 admission depended on UAR binaries without an explicit v2 capability, and native source/skill pins lagged the merged runtime work.

After this PR: incompatible instances receive a translated recovery message before endpoint registration or delegation. The 2.2.31 source inputs consume the integrated UAR, BossFang, full/mini skills, Compass and filesystem revisions; Compass skills are generated by a requested Mac/Windows job.

Fixes #: N/A — approved cross-repository integration child.

### Why we need it and why it was done in this way

The following tradeoffs were made: preserve older run observation and existing authentication ownership, but refuse unsupported v2-dependent effects. Reuse unchanged binaries only with actual immutable provenance.

The following alternatives were considered: pointer-only updates and silent protocol downgrade; neither fixes the observed stale payload mismatch.

Links to places where the discussion took place: https://github.com/GQAdonis/librefang/pull/151

### Breaking changes

Selected UAR instances must advertise tool_admission_v2 for dependent execution. Local settings remain available and incompatible instances receive an upgrade/reselection action.
