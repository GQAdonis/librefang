The Boss 2.2.31

Feature profile: uar-enabled. Includes the selected pinned UAR sidecar payloads for macOS Apple Silicon and Windows x64.

This release delivers macOS Apple Silicon and Windows x64 installers. macOS Intel and Windows ARM64 are deferred for this release; their existing 2.2.30 installers remain available from the download website with their original version labels. Linux is excluded.

Exact installer source commits, checksums, sizes and signing status are recorded in the immutable platform manifests and RELEASES.md. Publication does not imply completed installed acceptance.
