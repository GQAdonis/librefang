## Open C08.1 gaps

1. **Authorized explicit reassignment is not wired.** `bridge.rs` refuses an explicitly addressed different handler while an affinity exists, stating that a separate authorized reassignment is required. The storage `reassign` CAS exists but has no Gate-authorized caller. This is the correct current refusal, yet product task 1.3 requires the full explicit-target-over-affinity behavior after authorization. Keep 1.3 open until D-GATE is accepted and the authorized route-revision path is connected; do not weaken the task or claim that an explicit mention silently overrode affinity.
2. **Capability is narrower than the endpoint describes.** `GET /channels/route-capability` in `crates/librefang-api/src/routes/channels.rs` reports storage profile (`embedded_local` or `remote_shared`), operational status, native-source requirement and `cross_host_observers: false`, but does not enumerate the currently supported Discord-guild-only ingress profile or unsupported adapters/DMs/batches. Product task 1.4 remains open until the capability response states the actual adapter/source matrix and the unsupported/legacy behavior. An unavailable route store currently stops a qualifying durable message rather than silently falling back; that fail-closed behavior must be reflected in the product contract/status.
3. **No composed gate has run.** Static source tracing is not proof that migration 45 and conditional writes execute on real SurrealDB, that two processes resolve a conflict correctly, or that restart recovery and effect suppression work end to end. One final C08 production gate remains scheduled after C08.1–C08.3 wiring.
