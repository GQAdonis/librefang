## Open acceptance gaps

1. **No composed gate has run.** Static source tracing is not proof that migration 45 and conditional writes execute on real SurrealDB, that two processes resolve a conflict correctly, or that restart recovery and effect suppression work end to end. One final C08 production gate remains scheduled after C08.1–C08.3 wiring.
2. **Provider source is not an accepted checkpoint.** Gate, Fabric, and UAR candidates need the complete C08 production integration receipt before cross-host observation can be called supported. Gate-effect environment variables and a shared database do not substitute for source disclosure, recipient delivery, and independent cursor proof.
3. **SurrealDB pin is exact.** This BossFang source pins `surrealdb`, `surrealdb-core`, and `surrealdb-types` to `=3.3.0` in `Cargo.toml`, and `surreal-memory` to revision `b7e2093a267ca8655fbe85693c0ddfc52711ab6b`. UAR's `versions.toml` and Cargo manifest also pin 3.3.0; Fabric's Cargo manifest pins its client to `=3.3.0`. These are source pins, not operational database evidence. Historical baseline manifest revisions remain unchanged.
