## Eight material findings

### 1. Model selection and binding preserve routing identity, but selectable is not execution-compatible

**Source-only; high confidence.** The picker exposes enabled models from operational UAR/gateway sources. Gateway operational status is established by authenticated `/models` listing, whose schema retains only model IDs. The picker does not assess reasoning, tools, context, output ceilings, accepted fields, or endpoint dialect. It therefore offers a route that can still fail at first inference. The selected triple is explicit `{source, providerId, modelId}`, not an executable authority grant. See [picker:37](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/renderer/pages/settings/PrometheusSettings/UarTeamModelPicker.tsx:37), [gateway projection:85](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/UarModelSourceAdapter.ts:85), and [IPC schema:311](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/shared/ipc/schemas/prometheus.ts:311).

Boss main resolves the selected model again against the selected runtime generation, preserving credentials in main/protected UAR provider storage. The starter maps its immutable member's `local-default` request to that exact provider/model. Explicit setup can revise an existing non-executable matching binding with expected revision; it preserves an already active matching binding and refuses package/scope conflicts. There is no silent historical migration. See [model resolution:13](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/uarTeamModelSetup.ts:13), [starter binding:224](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/uarStarterDocuments.ts:224), and [revisioned setup:231](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/UarStarterAdministrationAdapter.ts:231).

### 2. Canonical pricing is correctly separate from the served alias, but does not certify other capabilities

**Source-only; high confidence.** Boss resolves only an enabled explicitly configured alias target for the selected gateway and an enabled matching provider connection. It registers a hashed private provider with the gateway endpoint, served alias, protected key, and canonical `pricing_identity`; unresolved price identity is an actionable setup refusal. UAR validates the exact catalog price and captures pricing identity separately from the real alias route. See [exact alias target:167](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/services/prometheus/literGatewayCatalog.ts:167), [registration:77](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/uarTeamModelSetup.ts:77), [price validation:120](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/registry.rs:120), and [route versus price:500](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/registry.rs:500).

The registration payload supplies no context/output limits, capability provenance, accepted request fields, or endpoint profile. `pricing_identity` must not be promoted into proof that the gateway accepts upstream-specific reasoning controls. The running gateway's actual alias implementation and transformed request remain a separate boundary.

### 3. Context metadata is not carried by the team gateway setup; budget and context are distinct limits

**Source-only; high confidence; earlier refusal observed.** `ModelConfig.context_window` is optional. Team gateway registration omits it. The runtime looks up the configured route's window, then that route's catalog entry, then falls back to 8,192. It does not use the canonical pricing target as a context identity. Boss has a catalog context lookup helper, but the team setup calls only the exact pricing-target helper. See [model metadata:88](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/registry.rs:88), [runtime window resolution:4657](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/uar/runtime/manager.rs:4657), [fallback/refusal:4771](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/uar/runtime/manager.rs:4771), and [Boss context helper:186](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/services/prometheus/literGatewayCatalog.ts:186).

The private starter budget is 4,096 aggregate tokens, 100,000 cost microunits and 120 seconds; these reservation ceilings do not establish model context capacity. Unknown catalog limits should remain unknown rather than being enlarged to pass a scenario. The existing member resource ceiling is the relevant context-composition repair: empty selected skills mean none, rather than ambient host inventory. See [private budget:239](/Users/gqadonis/Projects/prometheus/worktrees/the-boss-d01-build/src/main/ai/runtime/uar/uarStarterDocuments.ts:239) and [selection boundary:112](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/uar/compiler/collaboration/team_execution/resolution.rs:112).

### 5. The candidate thinking patch addresses the default trigger, not the architecture contract

**Uncommitted source-only; high confidence about scope, no runtime certification.** Baseline Kimi parameters were emitted for requested reasoning **or** implicit multi-turn use without explicit effort. The candidate removes the multi-turn trigger. It still emits `thinking: {type: enabled, keep: all}` when reasoning is requested and still chooses the dialect by model name. It neither declares accepted gateway fields nor translates an upstream reasoning setting into a gateway-supported shape. An explicitly requested reasoning operation remains unresolved by this patch. The companion candidate maps provider errors to stable categories, including `provider_invalid_request`; it does not supply a richer team diagnostic payload. See [candidate Kimi condition:517](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/prompt_dialect.rs:517), [error categories:37](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/provider_error.rs:37), and [candidate emitted code:2032](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/orchestrator.rs:2032).

There is already an exact host-owned endpoint request profile seam with model/endpoint/revision, accepted fields, transform and enforceable output ceiling. When a destination profile is supplied, `prepare_attempt` replaces legacy parameters with its exact settings. Therefore the bounded architecture decision should establish how this existing seam is resolved for team gateway routes, rather than create another dialect executor or assume the candidate controls every dispatch. See [profile contract:285](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/mod.rs:285) and [exact settings replacement:397](/Users/gqadonis/Projects/prometheus/worktrees/agent-fabric-c09-uar/src/llm/orchestrator.rs:397).

### 6. The lost actionable reason originates before Boss projection

**Observed symptom, source-confirmed cause; high confidence.** Actor threads retain both code and message. Team execution settlement selects only `Failed.code`; an empty code becomes `Some("")`, preventing the later uncertainty fallback. Boss's DTO retains nullable `stateReason`, and the UI renders it only when truthy. Boss does not drop an existing nonempty reason. Runtime owns classification/projection, Boss owns localized action guidance after the contract is agreed.

## Ownership decision needed before bounded repair

| Contract | Responsible authority | Boss responsibility |
|---|---|---|
| Immutable model requirements and requested prompt/content dialect | AgentDefinition/compiler; required unsupported semantics block activation | Display selected binding/diagnostics; do not infer execution support from an alias |
| Actual endpoint protocol, accepted fields, transforms, reasoning controls, output enforcement | Trusted UAR provider adapter and resolved endpoint profile; Liter owns its serialization/transport, gateway owns its exposed API/alias transform | Carry explicit selected route and trustworthy metadata/provenance; keep credentials protected; no arbitrary renderer request fields |
| Canonical price identity | Exact enabled gateway target plus UAR priced catalog validation | Preserve route-versus-price identity distinction and actionable unavailable-price refusal |
| Context and output limits | Resolved model/endpoint metadata plus UAR context planner | Show known limits/unknown state; private reservation defaults remain within authoritative team ceilings |
| Execution/effects/cancellation/recovery/usage | Existing UAR actor kernel and durable collaboration catalog | Fixed typed controls and authoritative projection only |
| Safe operational failure contract | UAR stable category plus deliberately bounded diagnostic/run reference | Translate agreed codes into actionable messages across existing locales |

Recommended decision for the parent document: bind team routes to the existing exact endpoint-settings contract; keep model-family prompt presentation separate from transport settings; retain explicit unknowns and current admission refusals. Approval must choose the supported scope for requested reasoning and metadata provenance. The candidate default-trigger/code repair can be assessed within that decision, but its presence is not acceptance evidence. No production repair is authorized or performed by this assessment.
