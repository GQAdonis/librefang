# Research plan

Scope: UAR local durable teams, both development and feedback-to-issue stories; protocols and future federation boundary.

Questions: Q1 existing kernel reuse and recovery gaps; Q2 lossless definition family; Q3 Codex/Claude/OpenCode/Kimi patterns and limitations; Q4 protocol version compatibility and streaming; Q5 authority and task/effect ownership; Q6 smallest complete delivery and measurable acceptance.

Method: Firecrawl discovery, Context7 official contracts, source inspection with immutable baselines, labelled claims, contradiction resolution, source graph and independent bounded review. No builds or runtime tests. Source verification is reading evidence.

All stages use the current Astra session except an isolated adversarial judge. Remote model research service, if used, is supplemental and must retain its own provenance.
